# Client Logos

Add your client/company logos here.

## Format Guidelines:
- **Recommended format**: PNG with transparent background
- **Recommended size**: 140-200px width, maintain aspect ratio
- **File naming**: `logo-1.png`, `logo-2.png`, `logo-3.png`, etc.

## Logo Requirements:
- High resolution (2x or 3x for retina displays)
- Clean, professional quality
- Transparent background preferred
- Consistent sizing across all logos

## Current Logo Files:
Place your logo files here and update the logos array in `components/home/TrustedBy.tsx`:

```typescript
const logos: Logo[] = [
  { name: 'Company Name', filename: 'logo-1.png', width: 140, height: 60 },
  // Add more logos...
];
```

## Example logos to add:
- logo-1.png - First client/company
- logo-2.png - Second client/company
- logo-3.png - Third client/company
- logo-4.png - Fourth client/company
- logo-5.png - Fifth client/company
- logo-6.png - Sixth client/company

Adjust width and height values based on your actual logo dimensions.
