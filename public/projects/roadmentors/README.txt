Road Mentors EdTech Platform Media Files
=========================================

Required media files:

Images:
-------
1.png - Platform overview / landing page
2.png - Course catalog interface
3.png - Learning dashboard / student view
4.png - AI course interface / content view

Video:
------
demo.mp4 - Platform demonstration video
video-thumb.png - Video thumbnail image

Recommended specs:
------------------
Images:
- Format: PNG or JPG
- Dimensions: 1920x1200 or 16:10 aspect ratio
- Quality: High-resolution
- File size: Optimized for web (< 500KB)

Video:
- Format: MP4 (H.264)
- Resolution: 1920x1080 (1080p) recommended
- Duration: 30-90 seconds for demo
- File size: < 10MB (use compression if needed)

Thumbnail:
- Format: PNG or JPG
- Dimensions: 1920x1080
- File size: < 200KB

Note: Add your actual Road Mentors screenshots and demo video to this folder.
